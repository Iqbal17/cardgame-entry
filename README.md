**Ember Duel** — an original elemental card duel. You and the rival Vex the Cinder start at 30 life. Each turn you gain 3 ember and draw up to 5 cards from a 24-card deck of four elements — Flame (damage), Tide (heal and draw), Thorn (shield), Spark (damage plus draw) — each told apart by colour and shape. Play two cards of the same element in a row to spark a combo (+1). Shield absorbs damage first and fades at your next turn. The rival plays a readable, counterable strategy: it goes lethal when it can, shields when hurt, and heals when it must. First to 0 life loses.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Keyboard: `E` end turn, `R` restart. No network, no build step — static files under `game/` only.
